# Standalone Power Law Beta Plot

This folder contains a self-contained script to generate the bound_beta.pdf plot without needing the full pipeline.

## Setup

### Step 1: Extract Data (One-time setup)

From the `pipeline/figures/` directory, run:

```bash
python extract_data_for_standalone.py
```

This will:
- Read all inference.h5 files from the production directories
- Extract the necessary configuration and precision data
- Create `powerlaw_data.h5` in this folder (~[size] MB)

### Step 2: Run the Standalone Plot Script

From this `standalone_powerlaw/` directory, run:

```bash
python plot_bound_beta.py
```

This will generate `bound_beta.pdf` with the beta vs PN order plot.

## Requirements

- numpy
- matplotlib
- h5py

## File Structure

```
standalone_powerlaw/
├── README.md                 # This file
├── plot_bound_beta.py        # Main plotting script (self-contained)
├── powerlaw_data.h5          # Data file (generated by extract_data_for_standalone.py)
└── bound_beta.pdf            # Output plot (generated by plot_bound_beta.py)
```

## Sharing

To share this plot with others:
1. Include this folder with both `plot_bound_beta.py` and `powerlaw_data.h5`
2. They can directly run `python plot_bound_beta.py` without needing access to the original inference files
3. No modification of paths or configuration needed

## Notes

- The data extraction (`extract_data_for_standalone.py`) must be run from `pipeline/figures/` because it searches for the original inference files
- The plotting script (`plot_bound_beta.py`) is completely self-contained and can be moved anywhere as long as `powerlaw_data.h5` is in the same directory
